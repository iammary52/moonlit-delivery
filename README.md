# 달빛 특송 · Moonlit Delivery

숲속 장난감 광장에서 두 배달원이 슬라임을 물리치는 한 화면 협동 액션 게임입니다.

[게임 열기](https://iammary52.github.io/moonlit-delivery/)

| 입력 | 이동 | 공격 | 회피 |
| --- | --- | --- | --- |
| 1P 키보드 | W A S D | F | G |
| 2P 키보드 | 방향키 | K | L |
| Xbox USB 패드 | 왼쪽 스틱 또는 방향 패드 | X | A |

패드를 연결한 뒤 브라우저에서 버튼을 한 번 누르면 인식됩니다. 패드가 한 대면 기본 2P이며, 배달원 선택에서 1P로 바꿀 수 있습니다. 두 대를 연결하면 패드 하나씩 사용할 수 있습니다. 일시정지는 Esc 또는 Xbox 메뉴 버튼입니다.

- 보리의 망치, 루미의 별지팡이, 토토의 도토리 장갑, 밤비의 잎 방패 중 두 가지를 고릅니다.
- 공격 버튼을 누르고 있으면 가까운 슬라임을 자동 조준합니다. 두 배달원이 같은 슬라임을 연달아 때리면 협동 공격이 터집니다.
- 떨어진 장비를 모으면 두 배달원 모두 공격력, 공격 속도, 연쇄 번개 효과가 강화됩니다.
- 여섯 챕터에 총 24라운드가 있으며, 브라우저가 라운드 종료 때 진행을 저장합니다.

블렌더로 렌더링한 여섯 가지 광장과 Canvas 2D 캐릭터 애니메이션을 사용합니다. 별도 빌드 단계나 서버가 필요하지 않습니다.
